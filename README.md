# 3D Protein Visualization and Analysis

## Overview

This project is an interactive web application developed using Python and Streamlit to visualize and explore protein and DNA structures in three dimensions.

## Features

* Retrieve molecular structures using PDB IDs.
* Upload PDB files for visualization.
* Visualize structures using different representations, including cartoon, stick, sphere, and surface.
* Explore ligand information.
* Display protein sequences and secondary structure information.
* Analyze amino acid composition.
* Compare sequences to identify potential mutations.

## Technologies Used

* Python
* Streamlit
* py3Dmol
* Requests
* Matplotlib
* RCSB Protein Data Bank (PDB)

## How to Run

1. Clone or download this repository.

2. Install the required dependencies:

   `pip install -r requirements.txt`

3. Start the application:

   `streamlit run app.py`

4. Open the local URL displayed in your terminal.

## Data Source

Protein and DNA structures can be retrieved from the RCSB Protein Data Bank.

https://www.rcsb.org/
